# 🌐 Portfolio Website

A modern, responsive one-page portfolio.

## 🚀 Features

* Clean & professional UI
* Fully responsive design
* Smooth scrolling navigation
* Skills, Projects, and Contact sections
* Interactive cards & hover effects

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* Font Awesome (icons)
* Google Fonts

## 📁 Project Structure

```
index.html
style.css
script.js
assets/images/profile.png
```

## 📌 How to Run

1. Download or clone the project
2. Open `index.html` in your browser
